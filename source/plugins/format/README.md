# FORMAT.WMF

Плагин Wild Commander Improved: разметка накопителя под FAT32 — MBR и один
раздел FAT32 на всё устройство. Заголовок type=`#03` (пункт F10 **FAT32
format**), две страницы: код и копия страницы драйвера панели.
Форматирование только быстрое: пишется служебная область тома, данные не
затираются.

## Запуск: не добавлять в wc.ini

Добавлять `FORMAT.WMF` в `[PLUGINS]` файла `wc.ini` (то есть в постоянное меню
F10) **не рекомендуется**: случайный выбор пункта в F10 может стоить данных
на диске. Плагин лежит в `/WC` и загружается вручную, когда он нужен:

1. в панели перейти в каталог `/WC` и нажать Enter на `FORMAT.WMF` — WC
   загрузит плагин (окно `FAT32 format LOADED!!!`);
2. запустить его из меню F10 — пункт **FAT32 format** появляется в конце
   списка и остаётся там до перезапуска WC.

Комплектный `wc.ini` строки `FORMAT.WMF` не содержит.

## Устройства

Все, что знает WC:

| Строка списка | Драйвер | Ёмкость |
|---|---|---|
| SD card, Z-Controller slot 1 / slot 2 | DSDZC | CSD карты (CMD9 по SPI `#77`/`#57`) |
| IDE Nemo, master / slave | DIDENEMO | IDENTIFY: LBA28 или C·H·S |
| IDE SMUC, master / slave | DIDESMUC | IDENTIFY: LBA28 или C·H·S |
| SD card, NeoGS | DSDNGS | CSD карты — своя программа на процессоре NeoGS |

Устройство, с которого загружен WC (ячейка CMOS `#B2`, как в WC), отмечено
` (WC boot drive)`; выбрать его можно, но плагин отказывает (окно ошибки
`WC was started from this drive` / `It cannot be formatted`).

Диски IDE без LBA (только CHS) драйвер WC понимает с 2026-11-18: вариант
драйвера с CHS едет в `FILEX.WMF` той же сборки (docs/03, раздел 2). Нужны
`boot.$C` и `FILEX.WMF` одной сборки.

У карты NeoGS ёмкость службе WC недоступна (она не читает CSD). Плагин
загружает в NeoGS свою программу (меньше 256 байт, с `#4000`), та выполняет
CMD9 и отдаёт 16 байт CSD; затем служба WC ставится заново (`DOS_SWP`,
`DEVINI`), запись идёт через неё. Служба WC рассчитана только на NeoGS
(`DEVINI` ждёт ответа `#8B` на команду `#1D`); если он не пришёл, пункт
NeoGS отвечает `Drive not found`.

## Окна

У каждого экрана своё окно `FAT32 FORMAT` (цвет окон WC), подсказка клавиш —
по центру нижней рамки, как в WC Setup. Ошибки и предупреждение перед
записью — отдельное красное модальное окно поверх (как окно ошибки WC):
заголовок `ERROR` или `WARNING`, внизу `Press any key`.

1. Список устройств: Up/Down — выбор, Enter — проверить устройство, Esc —
   выход.
2. `Checking the drive...`: выбор драйвера, `DEVINI`, ёмкость. Ошибки:
   `Drive not found`; `SD card did not report its size`; `Drive size or
   geometry not supported` (нет ёмкости, или головок не 1..16, или секторов
   на дорожке не 1..127). Любая клавиша — снова список.
3. Параметры: имя устройства, ёмкость (`256.0 MB (524288 sectors)`), у IDE —
   модель и адресация (`LBA` или геометрия CHS), у SD — тип карты по CSD
   (`SDSC`, `SDHC`, `SDXC`). Поля — колонкой, курсор на значении:
   - `Cluster size:  < Auto: 512 B >` — Left/Right: Auto, 512 B, 1, 2, 4, 8,
     16, 32 KB. Auto — таблица Microsoft (fatgen103): до 260 МБ — 512 B,
     до 8 ГБ — 4 KB, до 16 ГБ — 8 KB, до 32 ГБ — 16 KB, дальше — 32 KB.
   - `Volume label:  [___________]` — до 11 знаков: A–Z (строчные становятся
     заглавными), 0–9, пробел, `-`, `_`; Backspace стирает. Пустая метка —
     `NO NAME`.
   - Строка итога: `FAT32, 507904 clusters` или почему с этим кластером тома
     нет (`Cluster too large for this drive`, `Cluster too small for this
     drive`, `Drive too small for FAT32`); Enter тогда не действует.
   Стрелки — поле и размер, Enter — дальше, Esc — к списку.
4. Окно `WARNING`: `All data will be lost on`, устройство, ёмкость,
   `Format? (Y/N)`. Y начинает запись, любая другая клавиша возвращает к
   параметрам.
5. Ход записи: `Formatting <устройство>`, полоса из 40 клеток как в окне
   копирования WC (слева направо: `█` — пройдено, `▒` — осталось) и проценты;
   Esc — остановить (окно ошибки `Formatting stopped` / `The drive has no
   file system now`).
6. Итог: `Done: FAT32, 256.0 MB`, `Cluster 512 B, 507903 free clusters`,
   `Panels on this drive show its new root.` Любая клавиша — выход.

## Разметка

| Устройство | Начало раздела | Выравнивание данных | Тип раздела |
|---|---|---|---|
| SD | 8192 (4 МиБ) | 8192 секторов | `#0C` |
| IDE с LBA | 2048 (1 МиБ) | 2048 секторов | `#0C` |
| IDE без LBA | сектор 1 головки 1 цилиндра 0 (LBA = SPT) | по кластеру | `#0B` |

Раздел — до конца устройства (у CHS — до C·H·S, у IDE с LBA — не дальше
LBA28, как адресует драйвер). Поля CHS в MBR — по геометрии диска (у LBA —
255 головок, 63 сектора); за 1023-м цилиндром — цилиндр 1023, последняя
головка и последний сектор (у LBA — `1023/254/63`). Том: резерв
от 32 секторов (с добавкой до выравнивания области данных), две FAT,
размер FAT — по формуле fatgen103, корень — кластер 2, FSInfo в секторе 1,
копия загрузочных секторов с сектора 6, серийный номер — из часов CMOS.

Порядок записи:

1. нули с LBA 0 до начала раздела (старой MBR и разметки больше нет);
2. нули на резерв, обе FAT и кластер корня;
3. FSInfo и копия, начала обеих FAT, метка в корне;
4. копия загрузочного сектора (+6), затем загрузочный сектор;
5. MBR — последней;
6. сверка: MBR и загрузочный сектор читаются назад (окно ошибки
   `Read-back mismatch` / `Check the drive` при расхождении).

Оборванная запись (ошибка или Esc) оставляет устройство без тома, а не с
полуготовым томом: окно ошибки `Write error` / `The drive has no file system
now`.

## После записи

Панель, стоявшая на отформатированном устройстве, монтирует новый том
(`DOS_SWP`, `DEVINI`, `HDD` в странице панели, путь — корень); плагин
возвращает 3, WC перечитывает обе панели. Страница `W0` и `#21AF=#0E`
возвращаются такими, какими были при входе.

## Сборка и проверки

```text
source/plugins/format/build.ps1      FORMAT.WMF, обвязки тестов
source/plugins/format/tests/         fat32_layout.py — эталон разметки;
                                     test_layout — расчёт разметки на Z80
                                     против эталона; test_sectors — IDENTIFY,
                                     CSD и тип карты, MBR, загрузочный
                                     сектор, FSInfo, FAT, метка, полоса хода
```

Корневой `build.ps1` собирает плагин, гоняет оба теста и кладёт
`FORMAT.WMF` в `exe/WC` (`tools/install_format_runtime.py`); строку в
`[PLUGINS]` не добавляет, а оставшуюся от прежней сборки убирает.

Проверено в эмуляторе unreal-ng (2026-11-18): IDE Nemo с LBA (128 МиБ и
98 МБ) и SD через NeoGS (256 МиБ) — образ побайтно совпадает с эталоном,
Windows chkdsk ошибок не находит, WC монтирует новый том и пишет на него;
загрузка Enter'ом на `FORMAT.WMF` без строки в `wc.ini` и запуск из F10.
Через эмулятор не проверены SD Z-Controller (слот 1 — загрузочный, слота 2
нет) и диск без LBA (эмулятор не отдаёт IDENTIFY из заголовка HDF) — их
покрывают тесты. На настоящем ZX Evolution плагин проверен 2026-11-18.

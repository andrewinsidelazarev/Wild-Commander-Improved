# FTView Convert

Перекодирует любое видео в MJPEG AVI для плагина FTView (VDAC2/FT812, звук на
General Sound или FT812). Windows x64, одно окно: выбор файла, папка
результата, устройство звука и «Выполнить». Файл можно перетащить в окно или
на значок программы.

## Что получается

- Видео: MJPEG baseline 4:2:0, стандартные таблицы Хаффмана, **24 кадра/с**,
  около 2 Мбит/с — как у проверенного образца Muse (≈250 КБ/с чтения с SD).
- Звук (если он был в исходнике): 8 бит моно 22 050 Гц, формат — по
  переключателю «Звук для»:
  - **General Sound** — PCM без знака: так его выводит ЦАП GS. Без GS такой
    файл играет и звуковой блок FT812 (плагин переводит байты в знаковые).
  - **FT812** — µ-law, родной формат звукового блока FT812: больший
    динамический диапазон при тех же 22 КБ/с, байты идут в FT812 без
    пересчёта. Такой файл всегда звучит через FT812, даже если GS есть.
- Индекс `idx1` — для быстрой перемотки; полоса и перемотка работают в обоих
  вариантах.
- Файл по умолчанию кладётся рядом с исходником:
  `<имя> - FTView 576x320 24p GS.avi` (или `… FT812.avi`). Папку и имя можно
  сменить кнопкой «Изменить…» в строке «Сохранить в»; выбранная папка
  остаётся и для следующих файлов.

## Если Windows не даёт записать файл

Программа сама пробует записать в папку результата сразу после выбора
исходника и перед запуском, и называет причину под кнопкой «Выполнить»:

- файл с таким именем открыт в другой программе (плеер) или помечен «только
  для чтения» — закройте её или выберите другое имя;
- писать в папку можно только с правами администратора (проводник в этом
  случае спрашивает разрешение, а обычным программам Windows отказывает) —
  выберите другую папку или запустите программу от имени администратора;
- папку охраняет «Контролируемый доступ к папкам» Защитника Windows —
  разрешите в нём `FTViewConvert.exe` и
  `%LOCALAPPDATA%\FTViewConvert\ffmpeg-9.0.2.exe` или выберите другую папку.

Если проверка не прошла, «Выполнить» предлагает выбрать другое место.

## Как считается разрешение

Наибольший кадр при соотношении сторон исходника (с учётом SAR/DAR и поворота
видео с телефона): стороны кратны 16 (блок JPEG 4:2:0), площадь не больше
512×384 = 196 608 точек. Это предел плеера, при котором работают и звук через
FT812, и таблица перемотки в RAM_G. Ширина до 1024, высота до 688 (область
кадра 1024×700), и не больше самого исходника: маленькое видео не растягивается.

| Исходник | Результат |
|----------|-----------|
| 16:9 (1920×1080, PAL 16:9) | 576×320 |
| 4:3 | 512×384 |
| 2,39:1 | 672×288 |
| 9:16, телефон с поворотом | 320×576 |
| 320×240 | 320×240 |

## Сборка

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Нужен только Windows с .NET Framework 4 (компилятор `csc.exe` есть в системе).
Скрипт один раз скачивает статический ffmpeg 9.0.2 (essentials, gyan.dev — на
него ссылается ffmpeg.org), сверяет SHA-256 архива и вшивает `ffmpeg.exe` в
программу ресурсом. Результат — `Build/ftview-convert/FTViewConvert.exe`
(~105 МБ). При первом запуске ffmpeg распаковывается в
`%LOCALAPPDATA%\FTViewConvert`. Иконка `app.ico` строится скриптом
`make_icon.py` (Python с Pillow) и хранится готовой.

Пакетный режим без окна для сценариев и проверок:
`FTViewConvert.exe --batch <вход> <журнал> [gs|ft812]` (код выхода 0 —
успех, 2 — файл результата записать нельзя; по умолчанию звук для GS),
`--probe <вход> <журнал>` — только расчёт разрешения. В журнале строка
`write=` — `ok` или причина, по которой запись невозможна.

ffmpeg распространяется по GPL v3; его лицензия — `ffmpeg-LICENSE.txt` рядом
со сборкой.

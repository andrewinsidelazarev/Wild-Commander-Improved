## Файловое ядро

- **Кэш сектора FAT.** Потоковое чтение и запись файла (`LOAD512`, `SAVE512`,
  `LOADNON`, `LOAD256`) читали сектор FAT заново на каждом кластере. Теперь он
  читается один раз на 128 кластеров, а переход к следующему кластеру берётся
  из кэша — без обращения к карте. Кэш сбрасывают запись FAT, монтирование
  тома, смена и инициализация драйвера, начало чтения каталога и любое чтение
  FAT ядром, поэтому изменения на диске мимо него не проходят.
- **Что это даёт.** Длинные файлы проходятся заметно быстрее: в Unreal первая
  перемотка AVI на 52 МБ (кластер 4 КиБ) занимает 10,9 с вместо 29,9 с, а при
  воспроизведении сектор FAT читается около 0,5 раза в секунду вместо
  примерно 66. Выигрыш тем больше, чем длиннее файл и чем мельче кластер;
  на коротких файлах разницы нет.
- **LOADNON и LOAD256.** Общий потоковый вход затирал заданное число блоков,
  поэтому API 61 и API 60 проходили за вызов около 81 блока вместо
  запрошенного: плагин, читающий файл такими вызовами, получал не те данные,
  а `LOAD256` мог выйти за буфер. Ошибка была во всех выпусках v1.10i
  с 16 августа.

## Видеоплеер FTView (FT812 Viewer v1.21)

- **AVI покадрово на весь экран.** MJPEG AVI идёт кадр за кадром на 1024×768
  со сглаживанием, поверх кадра — полупрозрачная панель: полоса, время,
  подсказки. Она видна 15 с после нажатия любой клавиши, на паузе — всегда.
  Раньше AVI играл только штатный `CMD_PLAYVIDEO` чипа, без управления.
- **Звук на General Sound или FT812.** PCM 8 бит (araw) звучит на GS/NeoGS — драйвер
  загружается в GS через его ПЗУ, а без GS — на звуковом блоке FT812. Кадры
  идут точно по звуку. Ролики с другим звуком, как и раньше, играет
  `CMD_PLAYVIDEO`.
- **Управление:** Space — пауза (в конце ролика — просмотр сначала),
  Left/Right — ±10 с, Home — начало, PgUp/PgDn — соседний файл,
  Enter — список роликов, Esc — выход.
- **Быстрая перемотка:** по готовой таблице в самом файле (её пишет
  FTViewConvert) или по таблице, которую плеер строит по `idx1` при первом
  переходе.
- **Список роликов (Enter):** MJPEG AVI из каталога ролика по алфавиту,
  длинные имена (кириллица транслитом), курсор на текущем. Enter запускает
  выбранный, Esc — назад. Когда ролик доиграл, список открывается сам.
- **Сообщения:** AVI с видео не MJPEG сообщает «Unsupported video codec»
  вместо мусора на экране; окна закрываются любой клавишей; в «Cannot display
  file» видны номер сборки и причина (Reason NN).
- Плагин занимает 11 страниц пула плагинов вместо 10.

## Меню F10

- В меню F10 вернулись плагины, у которых есть своё окно при запуске из меню.
  В выпуске от 2026-09-28 их там не было:
  - **TR-DOS Mounter** — меню «Mount RS-232» (подключить диск A–D через
    RS-232) и «Dismount Drive» (отключить диск);
  - **TRDump** — снять образ дискеты в TRD-файл: дисковод, имя файла, число
    цилиндров, число повторов чтения;
  - **TRDispatcher** — создать в текущем каталоге пустой образ `TRD.trd`
    (80 дорожек, две стороны, 640 КиБ);
  - **TXT Editor** — открыть редактор с новым файлом `notepad.txt`.
- Меню показывает все плагины, которые сами заявляют запуск из F10, — по
  алфавиту, как раньше. Свои расширения файлов этому не мешают: по TRD- и
  SCL-файлам, из меню просмотрщиков и по F4 эти плагины запускаются как прежде.
- Просмотрщики текста Text/HEX Viewer и TXT/HEX VDAC2 в меню F10 по-прежнему
  не показываются: без файла им нечего открыть. Они запускаются по Enter или F3
  на файле и из меню просмотрщиков (Shift+F3).

## WC Setup

- В списке плагинов (Tab) группа «F10» совпадает с меню F10: TR-DOS Mounter,
  TRDump, TRDispatcher и TXT Editor перешли в неё из группы «file».

## Для авторов плагинов

- Меню F10 строится по байту `+197` заголовка `.WMF`: `#02` (заставка), `#03`,
  `#05`, `#11`, `#13` и `#15` — те же типы, которые ядро запускает из меню с
  `A=#03`. Свои расширения в заголовке (`+64`) на это не влияют.
- Просмотрщику, которому без файла нечего показать, F10 заявлять не нужно:
  Text/HEX Viewer и TXT/HEX VDAC2 теперь тип `#04` (только меню
  просмотрщиков), FT812 Viewer — `#00` (только по файлу).
